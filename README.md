# calculator
A simple, responsive, and user-friendly calculator coded by HTML, CSS and JS to perform basic arithmetic operations with ease. 

**Key Features:**
- ➕ Addition, subtraction, multiplication, and division
- 🧹 Clear and delete functionality
- ⚡ Instant calculation results
- 🎨 Clean and intuitive user interface
- 📱 Responsive design for different screen sizes
- ⌨️ Easy input and smooth user interaction
